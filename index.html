Cloud Connection

This file ships with no Firebase project baked in — that's intentional, so nothing sensitive ever ends up in the GitHub repo. Paste your own project's config below; it's saved only in this browser's local storage. The app then talks to Firestore directly, with no sign-in step, so your Firestore security rules must allow open read/write access — set this once in the Firebase Console under Firestore Database → Rules:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

Since this opens the database to anyone with the project config, it is meant for an internal team tool only — do not use this rule set if the file will be publicly reachable by outsiders.
